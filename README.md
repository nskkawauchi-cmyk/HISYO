# HISYO（秘書）

社内業務を自動化・効率化する「もう一人の事務員」アプリ。
ダッシュボードを起点に、メール・FAX・通知・入札管理・議事録・見積などの事務業務を一元管理します。

> ⚠️ このリポジトリは **HISYO 専用** です。**水道申請アプリとは完全に別物** で、フォルダもリポジトリも分離して管理します。

---

## 現在のステータス

**Phase 1（ダッシュボード基盤）プロトタイプ** — HTML / JavaScript / Tailwind CSS で作成済み。
この `index.html` をブラウザで開くと動作します（データは保存されないモック段階）。

次のステップ：GitHub へアップ → GitHub Pages で URL 発行 → Google 認証を設定。

---

## このプロトタイプでできること（Phase 1）

- **今日のメインタスク** … 重要度順に自動整列／手入力で追加／完了で消える
- **体調・気分に合わせた表示** … 「かなり疲れた」を選ぶと最優先だけに絞るなど、進め方を調整
- **外部連携の通知** … FAX・LINE・Teams・AI電話（アイブリー）を想定。HISYOが「急ぎ／重要」を判定
- **メール管理（仕分け）** … 優先返信／要確認／不要にAIが分類するイメージ。要約・本文表示・添付プレビュー・返信下書き（トーン切替）・確認事項の表示
- **予定調整** … 候補日の提示と確定、タスク化
- **よく見るサイト** … 毎日チェックするページを登録
- **お帰りなさい！不在中のたまりタスク** … 隔週出勤に対応

## 実装フェーズ（設計書 v2.0 より）

| Phase | 機能 | 優先度 |
|---|---|---|
| Ph.1 | ダッシュボード基盤 | 最優先 |
| Ph.2 | メール自動仕分け（Outlook / Xserver） | 最優先 |
| Ph.3 | FAX処理機能 | 高 |
| Ph.4 | 議事録自動作成 | 高 |
| Ph.5 | 会議資料自動作成 | 中 |
| Ph.6 | 入札管理の半自動化 | 中 |
| Ph.7 | せつびやさん連携 | 低 |

**方針：一気に実装せず、Phase 1 から順に「実装 → 確認 → リリース」を繰り返す。**

## 技術スタック（予定）

- フロントエンド：HTML / JavaScript / Tailwind CSS
- ホスティング：GitHub Pages
- 認証：Google アカウント（OAuth 2.0／登録アカウントのみ）
- メール連携：Microsoft Graph API（Outlook）/ Xserver IMAP
- ストレージ：OneDrive（Microsoft Graph API）
- 通知：Microsoft Teams（Microsoft Graph API）
- AI処理：Anthropic API
